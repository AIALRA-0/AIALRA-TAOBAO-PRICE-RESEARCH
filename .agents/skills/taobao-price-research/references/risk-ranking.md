# 风险与排序规则

## 最低价可行商品

最低价可行商品必须同时满足：

- 商品身份匹配度不是 `low`
- 成色符合用户要求
- 销售类型不是配件、定金、预售、租赁、拍卖或故障品
- 库存为 `in-stock` 或 `limited`
- 证据等级为 `A`
- 商品价能够解析为非负十进制数
- 风险等级不是 `high`

## 已知总额

已知总额按照下面的公式计算：

`商品价 + 已知运费 + 已知费用 - 已验证优惠`

未验证优惠不能扣除

返现不能扣除

运费或费用未知时，成本完整度为 `display-only`

运费和费用都已知时，成本完整度为 `complete`

## 决策类型

| 值 | 含义 |
|---|---|
| `lowest-verified-total` | 赢家拥有完整成本并且是同组可行商品中的最低已知总额 |
| `lowest-displayed-price` | 没有完整成本，赢家只代表最低已核验商品展示价 |
| `no-viable-offer` | 没有满足可行条件的详情证据 |
| `manual-verification-required` | 无法取得足够实时详情证据，需要用户或后续运行继续 |

## 风险分

风险分从 0 开始

脚本按照证据字段增加分数：

| 条件 | 分数 |
|---|---:|
| 商品身份匹配度为 `medium` | 15 |
| 店铺类型为 `marketplace` | 8 |
| 店铺类型未知 | 12 |
| 店铺评分未知 | 8 |
| 店铺评分低于 4.6 | 18 |
| 退货政策未知 | 8 |
| 保修信息未知 | 8 |
| 价格适用范围不是公开价 | 6 |
| 每个中等负面评价主题 | 4 |
| 每个严重负面评价主题 | 10 |
| 价格低于可比商品中位数的 60% | 25 |

风险等级映射：

- 0 至 19 为 `low`
- 20 至 39 为 `medium`
- 40 及以上为 `high`

风险分只用于一致排序

它不能代替用户对店铺、保修、退货和价格条件的最终判断

## 排序

先排除不可行商品

存在完整成本商品时，只在完整成本商品中选择最低已知总额

没有完整成本商品时，可以在详情已核验商品中选择最低展示价

总额相同时依次比较风险分、商品身份匹配度、店铺类型和原始顺序

最终 validator 会重新计算赢家条件，防止脚本或外部节点错误宣布赢家
